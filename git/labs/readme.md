# Git Hands-on Labs

Step-by-step practical exercises with terminal commands and expected outputs.

---

## 🛠️ Labs Curriculum

| Lab # | Title | Objective |
|---|---|---|
| **Lab 00** | [Git Installation & First-Time Setup](./lab00-installation.md) | Install Git on Windows, macOS, or Linux and configure your global username/email |
| **Lab 01** | [Git Basic Workflow & File Lifecycle](./lab01-basic-workflow.md) | Practice `git init`, `status`, `add`, `commit`, `diff`, and `log` from scratch |
| **Lab 02** | [Creating, Switching & Managing Local Branches](./lab02-branching-local.md) | Create, list, switch, isolate changes, and delete local branches |
| **Lab 03** | [Practicing Git Merge Strategies](./lab03-merge-strategies.md) | Hands-on Fast-Forward, No-FF (`--no-ff`), 3-Way merge, and Squash merge (`--squash`) |
| **Lab 04** | [Git Merge Conflicts & Abort Strategy](./lab04-merge-conflicts.md) | Deliberately trigger, inspect, resolve conflicts, and test `git merge --abort` |
| **Lab 05** | [GitHub Basics: Create, Clone, Push & Pull](./lab05-github-basics-clone-push-pull.md) | Create a repo on GitHub, clone locally, commit & push, simulate cloud edits, and pull |
| **Lab 06** | [Remote Collaboration & GitHub Flow](./lab06-pull-requests-and-github-flow.md) | SSH keys, upstream tracking (`-u`), branch pushes, Pull Requests, and code reviews |
| **Lab 05** | [GitHub Basics: Create, Clone, Push & Pull](./lab05-github-basics-clone-push-pull.md) | Create a repo on GitHub, clone locally, commit & push, simulate cloud edits, and pull |
| **Lab 06** | [Remote Collaboration & GitHub Flow](./lab06-pull-requests-and-github-flow.md) | SSH keys, upstream tracking (`-u`), branch pushes, Pull Requests, and code reviews |
