# DevOps Learning Repository

A structured, learner-friendly DevOps curriculum organized by tool. Each tool folder is self-contained with:
- **`concepts/`**: Core theory, visual SVG diagrams, and collapsible Q&A notes
- **`labs/`**: Step-by-step hands-on exercises and practical tutorials

---

## 🗺️ Curriculum & Modules

| Module | Description | Concepts | Labs |
|---|---|---|---|
| **[Git & VCS](./git/README.md)** | Distributed Version Control, branching, and team collaboration | [Concepts](./git/concepts/readme.md) | [Labs](./git/labs/readme.md) |
| **[Docker](./docker/README.md)** | Containerization, Dockerfile, networking, and volume storage | [Concepts](./docker/concepts/readme.md) | [Labs](./docker/labs/readme.md) |
| **[Kubernetes](./kubernetes/README.md)** | Container orchestration, Pods, Deployments, Services, Ingress | [Concepts](./kubernetes/concepts/readme.md) | [Labs](./kubernetes/labs/readme.md) |
| **[Ansible](./ansible/README.md)** | Configuration management, playbooks, inventory, and roles | [Concepts](./ansible/concepts/readme.md) | [Labs](./ansible/labs/readme.md) |
| **[Terraform](./terraform/README.md)** | Infrastructure as Code (IaC), HCL, state management, providers | [Concepts](./terraform/concepts/readme.md) | [Labs](./terraform/labs/readme.md) |
| **[GitHub Actions](./gh-actions/README.md)** | CI/CD pipelines, automated testing, deployment workflows | [Concepts](./gh-actions/concepts/readme.md) | [Labs](./gh-actions/labs/readme.md) |
| **[Prometheus & Grafana](./prometheus-grafana/README.md)** | Monitoring, metrics scraping, alerting, and observability dashboards | [Concepts](./prometheus-grafana/concepts/readme.md) | [Labs](./prometheus-grafana/labs/readme.md) |
